# Write notes on the on-screen piano keyboard

Path: Guide > Write and keep > Writing & Editing Music > Write notes on the on-screen piano keyboard
URL: https://maestro-pro.app/guide/editor-piano-keyboard/
Summary: The piano keys button in the score editor shows a keyboard; tap keys to write notes one after another while the bars being written stay at the top.

The **piano keys** button at the top of the score editor shows a piano keyboard above the modes. Press it again to hide the keyboard.

1. Select the note or rest where you want to start. With nothing selected, writing starts at the chosen bar, or at the beginning.
2. Choose a note length in the strip at the bottom.
3. Tap a key. That note is written, and the selection moves on to the next note or rest, so you can tap a tune in from left to right.

While the keyboard is showing, the row of bars you are writing moves to the top of the screen, so the keyboard never covers it.

- Swipe the keyboard sideways for higher and lower notes. Each C is named; C4 is middle C.
- The **stack** button beside the keyboard adds each key you tap to the note just written, to build a chord. Turn it off to carry on with single notes.
- The **arrow** button skips to the next note or rest without writing anything.
- A key tapped on a selected note changes that note's pitch.
- **Undo** takes back one note at a time.

Sharps and flats are spelled to suit the key signature. The keyboard writes on any staff, including [guitar tab](https://maestro-pro.app/guide/write-guitar-tab/).
