# Change the tuning pitch (A = 440 Hz)

Path: Guide > Practise > Tuner & Wait for Me > Change the tuning pitch (A = 440 Hz)
URL: https://maestro-pro.app/guide/change-concert-pitch/
Summary: A = 440 Hz can be changed between 415 and 466 for baroque or orchestral tuning.

A = 440 Hz can be changed to any value from 415 to 466 Hz, for baroque or orchestral tuning.
