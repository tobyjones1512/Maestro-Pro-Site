# Drag files onto the window

Path: Guide > Start here > Your Library > Drag files onto the window
URL: https://maestro-pro.app/guide/drag-files-onto-the-window/
Summary: Drag files from the Files app straight onto the Maestro Pro window to import them.

Drag files from the Files app straight onto the Maestro Pro window to import them. If a file is greyed out or Import Score does nothing, see [Import does nothing or shows a file greyed out](https://maestro-pro.app/guide/import-does-nothing-or-greyed-out/).
