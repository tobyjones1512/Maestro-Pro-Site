# Import several files at once

Path: Guide > Start here > Your Library > Import several files at once
URL: https://maestro-pro.app/guide/import-several-files/
Summary: Choose more than one file in the import dialog and they all arrive together.

Import Score lets you choose several files at once. To bring in everything in a folder, use [Import Folder](https://maestro-pro.app/guide/import-a-folder/).
