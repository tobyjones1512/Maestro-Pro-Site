# I lost the TestFlight link

Path: Guide > Plans and licences > Install with TestFlight > I lost the TestFlight link
URL: https://maestro-pro.app/guide/lost-the-testflight-link/
Summary: The key email includes the TestFlight link, and the install page has it too.

The email that carries your licence key also includes the TestFlight install link, so [recovering your licence key](https://maestro-pro.app/key.html) sends it again. The [install page](https://maestro-pro.app/install/) shows the link as well.
