# The Professional plan

Path: Guide > Plans > Plans and pricing > The Professional plan
URL: https://maestro-pro.app/guide/professional-plan/
Summary: Everything, including the score editor, medleys and version history with GitHub sync.

Professional includes everything, including the score editor. You can write and change music, build medleys, and keep version history with branches, merges and GitHub sync.

Professional is a subscription you start inside the app, managed in your Apple Account settings.
