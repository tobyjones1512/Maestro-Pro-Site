# Guitar tab: read any staff as tablature

Path: Guide > Write and keep > Writing & Editing Music > Guitar tab: read any staff as tablature
URL: https://maestro-pro.app/guide/guitar-tab/
Summary: Any staff can be shown as guitar tablature: fret numbers on six string lines, with the rhythm on stems underneath.

**Guitar tab** (tablature) shows each note as a fret number on one of six lines, one line for each string, with the rhythm on stems underneath as in ordinary notation. Maestro Pro can show any staff as tab and turn it back into notes again.

1. Open the score editor and choose **Bars** mode.
2. Open the **Staves** menu.
3. Choose **Show Staff 1 as Guitar Tab** (there is one for each staff). **Show Staff 1 as Notes** turns it back.
4. **Add Guitar Tab Staff** adds a new, empty tab staff under the others.
5. Press **Save**.

The same choices are under the staff's name in the touch and hold menu of a bar. **New Blank Score** has **Guitar Tab** among its staves, to start a tab score from nothing. A MusicXML file that already has a tab staff opens as tab, on the strings the file asks for.

The notes are the same notes either way, so a tab staff plays, transposes, prints, exports and works with Wait for Me and Record like any other staff. Exported MusicXML keeps the tab, with each note's string and fret, for other notation apps.

Tab uses standard guitar tuning (E A D G B E, lowest string to highest). Other tunings and other instruments' tab are not available. A cross (×) in place of a number marks a note the guitar cannot reach in this tuning.

Changing a staff needs the score editor, which is part of the Professional plan.
