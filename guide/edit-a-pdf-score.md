# Edit a score that came from a PDF

Path: Guide > Write and keep > Writing & Editing Music > Edit a score that came from a PDF
URL: https://maestro-pro.app/guide/edit-a-pdf-score/
Summary: The app first reads a PDF, and the editor works on a copy of what it read.

A PDF is first read by the app, and the editor works on a copy of what it read. If the app read a scan wrongly, import a MusicXML file of the piece instead, or see [Notes in a PDF look wrongly read](https://maestro-pro.app/guide/pdf-notes-read-wrongly/).
