# Put shortcuts back

Path: Guide > Settings and help > Keyboard Shortcuts > Put shortcuts back
URL: https://maestro-pro.app/guide/reset-shortcuts/
Summary: The arrow beside a shortcut resets it, and Reset All to Defaults resets them all.

The arrow next to a shortcut puts it back, and **Reset All to Defaults** puts them all back.
