# Karaoke MIDI (.kar) files

Path: Guide > Sound and words > Lyrics & Karaoke > Karaoke MIDI (.kar) files
URL: https://maestro-pro.app/guide/karaoke-midi-files/
Summary: Karaoke MIDI files contain their own words.

Karaoke MIDI (.kar) files contain their own words, so you do not need a separate lyrics file. Import them with **Import Score**.
