# Notes in a PDF look wrongly read

Path: Guide > Settings and help > Troubleshooting > Notes in a PDF look wrongly read
URL: https://maestro-pro.app/guide/pdf-notes-read-wrongly/
Summary: Only printed notation can be read and scans need to be straight and clear; try a MusicXML file instead.

Only printed notation can be read, and scans need to be straight and clear. For a scan the app cannot read well, import a MusicXML file instead; many are free online.
