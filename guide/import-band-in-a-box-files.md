# Band-in-a-Box files

Path: Guide > Start here > Your Library > Band-in-a-Box files
URL: https://maestro-pro.app/guide/import-band-in-a-box-files/
Summary: Band-in-a-Box files cannot be read; export MusicXML and audio from Band-in-a-Box instead.

Band-in-a-Box files cannot be read, because that is a closed format. In Band-in-a-Box, save as MusicXML for the notation and as audio for the backing, then import both.
