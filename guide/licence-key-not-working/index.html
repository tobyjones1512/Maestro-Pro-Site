    My licence key is not working

    • Check the key was typed exactly as sent. Copying it from the email is the safest way.
    • If the key was cancelled, it stops working after the date given in the cancellation email.
    • If you have more than one key, try the one for your current plan. See more than one licence key.
    • If it says the licence is already in use on 3 devices, remove a device and try again.
    • Recover your licence key to get a fresh email with every active key.
