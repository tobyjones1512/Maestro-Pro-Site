# Band-in-a-Box files will not open

Path: Guide > Settings and help > Troubleshooting > Band-in-a-Box files will not open
URL: https://maestro-pro.app/guide/band-in-a-box-files/
Summary: They cannot be read; save as MusicXML for the notation and as audio for the backing.

Band-in-a-Box files cannot be read (a closed format). In Band-in-a-Box, save as MusicXML for the notation and as audio for the backing.
