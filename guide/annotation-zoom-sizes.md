# Annotations and zoom

Path: Guide > Practise > Annotating > Annotations and zoom
URL: https://maestro-pro.app/guide/annotation-zoom-sizes/
Summary: Each zoom size keeps its own drawing so it stays lined up with the music.

Each zoom size keeps its own drawing, so your ink stays lined up with the music. A drawing made at one zoom size does not appear at another.
