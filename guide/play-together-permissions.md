# Local Network permission

Path: Guide > Together > Play Together > Local Network permission
URL: https://maestro-pro.app/guide/play-together-permissions/
Summary: Allow the Local Network permission if asked; devices find each other over Wi-Fi and Bluetooth, with no account.

Allow the Local Network permission if asked. Devices find each other over Wi-Fi and Bluetooth, with no account. Messages go directly between the devices and are encrypted.
