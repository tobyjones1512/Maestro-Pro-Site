# Import does nothing or a file is greyed out

Path: Guide > Settings and help > Troubleshooting > Import does nothing or a file is greyed out
URL: https://maestro-pro.app/guide/import-does-nothing-or-greyed-out/
Summary: Choose All Files in the Files browser, or drag the file onto the window.

If Import Score does nothing or shows a file greyed out, choose **All Files** in the Files browser, or drag the file onto the window. Check the file type is one of the [supported file types](https://maestro-pro.app/guide/supported-file-types/).
