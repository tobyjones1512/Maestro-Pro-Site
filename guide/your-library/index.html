Your Library

Everything you import lives in the library and stays on the device. It is also kept in iCloud when iCloud Drive is on.

  • Bringing music in

Bringing music in

Import Score takes PDF, MusicXML (.musicxml, .xml, .mxl), MIDI and karaoke (.mid, .kar), lyrics (.lrc, .txt), CD+Graphics karaoke (.cdg) and Maestro Pro (.maestropro) files. Several can be chosen at once.

You can also drag files from the Files app straight onto the window, or choose Maestro Pro from the share sheet of another app (Files, Mail, Safari, Messages…) to import what you are looking at.

Import Folder reads every supported file in a folder. In Settings, Link a Folder keeps a folder in step with the library so new files appear by themselves.

New Blank Score starts an empty score to write yourself: you choose the name, time signature, key, number of bars, staves (treble, bass or piano) and tempo.

Lyrics with Backing: choose a backing track and the app finds its timed lyrics online, for a karaoke-style screen. You can also choose a lyrics file along with the backing track.

More on this topic

  • Supported file typesPDF, MusicXML, MIDI, karaoke, lyrics, CD+Graphics and Maestro Pro files can all be imported.
  • Import a scoreTap Import Score, choose your files, and they appear in the library.
  • Import a PDF scorePDFs are read by the app, which only reads printed notation, and scans need to be straight and clear.
  • Import MusicXML filesMusicXML files (.musicxml, .xml, .mxl) import like any other score and can be edited.
  • Import MIDI and karaoke filesMIDI and karaoke (.mid, .kar) files import with Import Score; karaoke files carry their own words.
  • Import several files at onceChoose more than one file in the import dialog and they all arrive together.
  • Drag files onto the windowDrag files from the Files app straight onto the Maestro Pro window to import them.
  • Import from another app's share sheetChoose Maestro Pro in the share sheet of Files, Mail, Safari, Messages and other apps.
  • Import a whole folderImport Folder reads every supported file in a folder.
  • Link a folder to the libraryIn Settings, Link a Folder keeps a folder in step with the library so new files appear by themselves.
  • Start a blank scoreNew Blank Score creates an empty score with the name, time signature, key, bars, staves and tempo you choose.
  • Lyrics with BackingChoose a backing track and the app finds its timed lyrics online for a karaoke-style screen.
  • Keep your library in iCloudYour library is stored on the device and is also kept in iCloud when iCloud Drive is on.
  • Set-lists for rehearsals and gigsBuild set-lists for a lesson, a rehearsal or a concert.
  • Scanning paper musicScanning printed music with the camera is planned for a future update and is not in the app today.
  • Band-in-a-Box filesBand-in-a-Box files cannot be read; export MusicXML and audio from Band-in-a-Box instead.
