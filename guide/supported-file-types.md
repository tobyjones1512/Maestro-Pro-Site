# Supported file types

Path: Guide > Start here > Your Library > Supported file types
URL: https://maestro-pro.app/guide/supported-file-types/
Summary: PDF, MusicXML, MIDI, karaoke, lyrics, CD+Graphics and Maestro Pro files can all be imported.

Import Score takes:

- PDF
- MusicXML (.musicxml, .xml, .mxl)
- MIDI and karaoke (.mid, .kar)
- lyrics (.lrc, .txt)
- CD+Graphics karaoke (.cdg)
- Maestro Pro (.maestropro) files

Band-in-a-Box files cannot be read, because that is a closed format. See [Band-in-a-Box files](https://maestro-pro.app/guide/band-in-a-box-files/).
