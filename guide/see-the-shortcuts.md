# See the keyboard shortcuts

Path: Guide > Settings and help > Keyboard Shortcuts > See the keyboard shortcuts
URL: https://maestro-pro.app/guide/see-the-shortcuts/
Summary: On a Mac shortcuts are shown in the Playback, Score and View menus; on an iPad hold the Command key.

On a Mac nearly everything has a keyboard shortcut, shown in the Playback, Score and View menus. On an iPad with a keyboard, hold the Command key to see them. Single keys (like the space bar) only work when you are not typing in a box.
