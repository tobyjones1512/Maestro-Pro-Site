# Import MusicXML files

Path: Guide > Start here > Your Library > Import MusicXML files
URL: https://maestro-pro.app/guide/import-musicxml-files/
Summary: MusicXML files (.musicxml, .xml, .mxl) import like any other score and can be edited.

Import MusicXML (.musicxml, .xml or .mxl) with **Import Score**. It is the best format for a score you want to edit, because the score editor changes the notes in a MusicXML score. If a scan reads badly, a MusicXML file of the piece is the reliable alternative.
