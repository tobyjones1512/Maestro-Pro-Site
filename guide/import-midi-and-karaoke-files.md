# Import MIDI and karaoke files

Path: Guide > Start here > Your Library > Import MIDI and karaoke files
URL: https://maestro-pro.app/guide/import-midi-and-karaoke-files/
Summary: MIDI and karaoke (.mid, .kar) files import with Import Score; karaoke files carry their own words.

Import MIDI and karaoke files (.mid, .kar) with **Import Score**. Karaoke MIDI (.kar) files contain their own words, so lyrics appear without a separate file. See [karaoke MIDI files](https://maestro-pro.app/guide/karaoke-midi-files/).
