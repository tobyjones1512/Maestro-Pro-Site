# Install with TestFlight

Path: Guide > Plans and licences > Install with TestFlight

Summary: Maestro Pro is installed through Apple's TestFlight app until it reaches the App Store.

Maestro Pro is installed through Apple's TestFlight app until it reaches the App Store, which is coming soon. You need a licence to use it.
