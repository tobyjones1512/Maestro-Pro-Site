# Import a whole folder

Path: Guide > Start here > Your Library > Import a whole folder
URL: https://maestro-pro.app/guide/import-a-folder/
Summary: Import Folder reads every supported file in a folder.

**Import Folder** reads every supported file in a folder. If you want new files to keep appearing by themselves, [link a folder](https://maestro-pro.app/guide/link-a-folder/) instead.
