# Export as a MIDI file

Path: Guide > Write and keep > Share, Export & Print > Export as a MIDI file
URL: https://maestro-pro.app/guide/export-as-midi/
Summary: Share, Export as MIDI saves the notes as a standard MIDI file for any other music program.

1. Press and hold the score in the library and choose **Share**, or open the score and tap the Share button.
2. Choose **Export as MIDI…**, then where to save or send it.

The file (.mid) has the notes in the key shown, with repeats played out, at the score's tempo, and a track for each staff. Open it in GarageBand, Logic or any other program that reads MIDI. A PDF score must have been opened once first, so its notes have been read. Export needs the Performer plan or higher.
