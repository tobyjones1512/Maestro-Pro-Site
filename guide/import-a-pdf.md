# Import a PDF score

Path: Guide > Start here > Your Library > Import a PDF score
URL: https://maestro-pro.app/guide/import-a-pdf/
Summary: PDFs are read by the app, which only reads printed notation, and scans need to be straight and clear.

Import a PDF with **Import Score** like any other file. The app reads the notation from the page and then follows it as it plays. Only printed notation can be read, and a scan needs to be straight and clear.

If the app reads a scan badly, import a MusicXML file of the piece instead; many are free online. If a PDF plays the wrong number of beats, see [a PDF plays the wrong number of beats](https://maestro-pro.app/guide/pdf-plays-wrong-number-of-beats/).
