# Change a shortcut

Path: Guide > Settings and help > Keyboard Shortcuts > Change a shortcut
URL: https://maestro-pro.app/guide/change-a-shortcut/
Summary: In Settings under Keyboard Shortcuts, click a shortcut and press the keys you want instead.

Open Settings ▸ Keyboard Shortcuts. Click a shortcut, then press the keys you want to use instead. **Delete** takes the shortcut away, and **Escape** leaves it as it was. A shortcut that is already in use moves to the action you give it to, and the page says so.
