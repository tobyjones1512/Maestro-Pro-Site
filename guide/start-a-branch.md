# Start a branch to try an idea

Path: Guide > Write and keep > Version History & GitHub > Start a branch to try an idea
URL: https://maestro-pro.app/guide/start-a-branch/
Summary: New Branch starts a separate line of edits from now or from any earlier version.

**New Branch** starts a separate line of edits, from now or from any earlier version, so you can try something without touching the main score. Switching branches first saves your unsaved edits.
