# If you have more than one licence key

Path: Guide > Plans and licences > Licences and keys > If you have more than one licence key
URL: https://maestro-pro.app/guide/several-licence-keys/
Summary: If you have subscribed more than once, the email lists every active key with its plan.

If you have subscribed more than once with the same email address, the key email lists every active key and names the plan each one belongs to. Use the key for the plan you want to use. Cancelled keys are not included.
