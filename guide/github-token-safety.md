# Where your GitHub token is kept

Path: Guide > Write and keep > Version History & GitHub > Where your GitHub token is kept
URL: https://maestro-pro.app/guide/github-token-safety/
Summary: The token is kept in your device's Keychain and sent only to GitHub.

If you connect a score to a GitHub repository, the app talks to GitHub using a personal access token you provide. The token is kept in your device's Keychain and is sent only to GitHub. Pushing sends your score's versions to the repository you chose, and nothing else.
