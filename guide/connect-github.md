# Connect a score to GitHub

Path: Guide > Write and keep > Version History & GitHub > Connect a score to GitHub
URL: https://maestro-pro.app/guide/connect-github/
Summary: Connect a score to your own GitHub repository and push its version history there.

You can connect a score to a GitHub repository of your own and push its whole version history there. The app talks to GitHub using a personal access token that you provide. Connecting your own GitHub repositories and adding tracks from them is included even on the Free plan; version history with GitHub sync is part of Professional. GitHub needs the internet.
