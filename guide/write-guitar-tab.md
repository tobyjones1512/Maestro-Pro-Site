# Write and edit guitar tab

Path: Guide > Write and keep > Writing & Editing Music > Write and edit guitar tab
URL: https://maestro-pro.app/guide/write-guitar-tab/
Summary: On a tab staff, touch a string to put in its open note, then use the Fret buttons; drag a note to another string.

On a tab staff the editor works in strings and frets. Use **Notes** mode.

1. Choose a note length in the strip at the bottom.
2. Touch a rest on the line of the string you want, and lift. The open string (fret 0) goes in, and is selected.
3. Use the **Fret** buttons in the strip (minus and plus, with the fret number between them) to move it up or down one fret at a time.
4. To play the same note on another string, drag the note up or down to that string. It moves only if that string can play the note.

A key on the [on-screen piano](https://maestro-pro.app/guide/editor-piano-keyboard/) or a [MIDI instrument](https://maestro-pro.app/guide/write-with-a-midi-instrument/) also writes onto tab: the note goes on the string where its fret is lowest, and notes of a chord are spread over different strings.

Lengths, rests, ties, dynamics, bars, repeats and everything else work as on any other staff. If a fret runs past the end of a string, the note moves to another string that can play it.
