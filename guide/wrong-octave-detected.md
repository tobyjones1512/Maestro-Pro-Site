# It hears the wrong octave

Path: Guide > Settings and help > Troubleshooting > It hears the wrong octave
URL: https://maestro-pro.app/guide/wrong-octave-detected/
Summary: Try Accept Any Octave if the tuner or Wait for Me still hears the wrong octave.

If it still hears the wrong octave after you have raised the microphone sensitivity, try **Accept Any Octave**. See also [The microphone cannot hear me](https://maestro-pro.app/guide/microphone-cannot-hear-me/).
