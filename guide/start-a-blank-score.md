# Start a blank score

Path: Guide > Start here > Your Library > Start a blank score
URL: https://maestro-pro.app/guide/start-a-blank-score/
Summary: New Blank Score creates an empty score with the name, time signature, key, bars, staves and tempo you choose.

**New Blank Score** starts an empty score to write yourself. You choose the name, time signature, key, number of bars, staves (treble, bass or piano) and tempo. Writing and editing needs the score editor, which is part of the Professional plan.
