# Save a version

Path: Guide > Write and keep > Version History & GitHub > Save a version
URL: https://maestro-pro.app/guide/save-a-version/
Summary: In the score editor, History and Save Version keep a snapshot you can return to.

In the score editor, tap **History**. **Save Version** keeps a snapshot you can go back to. Saving in the editor also records one.
