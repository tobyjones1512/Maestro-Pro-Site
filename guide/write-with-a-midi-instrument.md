# Write notes with a MIDI keyboard or instrument

Path: Guide > Write and keep > Writing & Editing Music > Write notes with a MIDI keyboard or instrument
URL: https://maestro-pro.app/guide/write-with-a-midi-instrument/
Summary: Plug a MIDI instrument into an iPad or Mac and play: each note is written at the selection in the score editor, and held keys make chords.

In the score editor you can write by playing. It works on iPad and Mac.

1. Plug a MIDI keyboard or other MIDI instrument in with USB. A Bluetooth MIDI instrument works once the device has paired with it.
2. Open the score editor and select the note or rest where you want to start.
3. Choose a note length in the strip at the bottom.
4. Play. Each note is written at the selection, which then moves on to the next note or rest.

Hold one key and press others to write a chord. The [on-screen piano keyboard](https://maestro-pro.app/guide/editor-piano-keyboard/) does not need to be showing; when it is, the keys you hold light up on it and the bars being written stay at the top of the screen.

This is step entry: the note length comes from the strip, not from how long you hold the key, and the app does not record your timing. Choose the length before you play the note. Write a rest by skipping (the arrow button beside the on-screen keyboard) or in Rests mode.

If nothing happens when you play, see [My MIDI instrument is not detected](https://maestro-pro.app/guide/midi-instrument-not-detected/).
